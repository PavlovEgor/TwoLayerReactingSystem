# TwoLayerReactingSystem

Плагин OpenFOAM для конвекции с реакцией нейтрализации A + B → C + H₂O в
несмешивающейся двухслойной системе (HCl в пентаноле / NaOH в воде) в вертикальной
ячейке Хеле-Шоу. Модель: Bratsun et al. 2023, *Phil. Trans. R. Soc. A* 381: 20220178.

Структура и скрипты сделаны по образцу плагинов v2512 (`plugins/avalanche`). Собрано
и проверено только на v2412: v2512 на этой машине не установлен.

## Запуск

```sh
source <openfoam>/etc/bashrc
./Allrun --profile smoke                        # окружение, сборка, проверка цепочки (минуты)
./Allrun --profile short --cpus 16              # сетка 100x200
./Allrun --profile full --cpus 64 --cpus-per-case 8   # сетка статьи, для сервера
```

Результаты: `validation/results/<profile>/summary.md` и графики. Готовые кейсы
пропускаются, прерванные параллельные продолжаются с последнего времени.
`--slurm` запускает кейсы через `AsyncSlurmFoamCase` из foamlib (на Slurm не проверялось).

Отдельно: `./Allwmake`, `./Allwclean`, `bin/setup-venv` (`.venv` с foamlib),
`NPROCS=8 tutorials/twoLayerReactingFoam/pentanolWaterHCl-NaOH/Allrun`.

## Модель

Вместо ψ–ω статьи решаются те же уравнения в переменных p–U: иначе явное вихревое
условие на границе при Sc≈300 сильно ограничивает шаг.

```
ρ(∂U/∂t + 6/5 ∇·(φU)) = −∇p + μ∇²U − 12μ/h² U + ρk g
ρk = ρ(βA A + βB B + W(t) βC C)
```

Граница — внутренние грани на плоскости `interfacePoint`: φ=0, нет потока B и C, A и его
поток непрерывны, μ на грани — гармоническое среднее (непрерывность скорости и сдвигового
напряжения, Φ₁=ηΦ₂). Давление в слоях развязано, у каждого своя опорная ячейка. Из-за
этого GAMG сходится плохо, поэтому для p используется PCG/DIC.

Единицы — СИ. νнижн=10⁻⁶ м²/с принята, остальное следует из табл. 1. Единица времени
h²/Dₐ = 430.6 с. Da=1000 фиксировано, поэтому k зависит от A₀.

## Несоответствия в самой статье

- Кривая ρ на рис. 2a сдвинута на ≈0.49 относительно формулы (2.8).
- ΔV_w на рис. 2b в 2 раза меньше, чем даёт (2.14) с μ/ρ из статьи (V_m≈0.0226 против
  0.045 л/моль). По умолчанию взято 0.045: так сходятся Kρ рис. 3b. Значение 0.0226 есть в
  исследовании как вариант.
- В (2.14) лишний множитель h в числителе, он несовместим по размерности. Здесь
  ΔV_w/V_rz = V_m∫∫C dA/(L·ω).
- Панель γ=0.76 рис. 3b: форма совпадает, но подписи оси сдвинуты на ≈0.4 (дальнее поле
  должно быть γ·R_B=1.85, подписано 2.3).
- Подпись рис. 5: B₀=0.5 M при A₀=2 M противоречит γ=0.4. В исследовании взято γ=0.4.
- Время: t\*=1 соответствует 431 с, а рис. 5 при 1040 с (t\*=2.4) похож на рис. 4b при t\*=10.
  Статья этого не обсуждает.

## Статус валидации

Подтверждено расчётами:

- Базовое состояние: OpenFOAM против 1D rms ρ ≤ 0.0003 при γ ≤ 1, против рис. 3b 0.011
  (γ=0.4) и 0.014 (γ=0.1); Kρ = 0.88 / 1.04 / 1.31 / 2.83 против 0.9 / 1.0 / 1.3 / 2.8.
- Сохранение ∫B+∫C, параллельный запуск с границей на процессорных гранях.
- Качественно: при γ=0.4 выровненная линия кончиков пальцев и вытягивание ячеек, как на рис. 4b.

Не завершено:

- Режимы DCC и RT не считались. Рис. 4 в целом и карта режимов не сравнены.
- Сетка статьи при γ=0.4 посчитана только до t\*=2. Глубина фронта при t\*=1: 4.78h против
  5.57h на рис. 4b. На 100×200 — 3.26h, то есть эта сетка ещё не сошлась.
- Роль воды, главный вывод статьи, пока не подтверждена. На 100×200 с одним seed средняя
  глубина почти не меняется, а шероховатость без воды при t\*=3 выше (2.56 против 1.1–1.8),
  при t\*=4 разница уже в пределах разброса.
- Плюмы в верхнем слое бледнее, чем в статье: A в них выше (≈0.7–0.9 на
  100×200). Причина не выяснена, нужно смотреть на сетке статьи.
- Критерии режимов в `analysis.py` (`regime`) эвристические и не откалиброваны.

Замечания:

- При γ=2 реакция прижата к границе, ω порядка шага сетки, поэтому W и Kρ зависят от
  сетки (0.62 против 0.55 в 1D).
- Конкретный рисунок пальцев зависит от шума и декомпозиции. Сравнивать нужно статистику,
  а не отдельные картины.
